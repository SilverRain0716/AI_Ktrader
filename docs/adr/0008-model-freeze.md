# ADR 0008 — 제공자는 갈아끼울 수 있게 하되 페이퍼 기간에는 동결한다, 그리고 은퇴 캘린더가 착수 마감을 만든다

- 상태: 채택
- 날짜: 2026-08-30
- 관련: [ADR 0005](0005-backtest-scope.md), [ADR 0006](0006-edge-hypothesis.md), [ADR 0007](0007-judgment-engine.md)

## 맥락

[ADR 0007](0007-judgment-engine.md) 이 호출 위치를 "저장소 안 도구 없는 API 호출"로 정했고 동결 정책을 선언했지만, **어느 제공자·어느 모델인지**는 정하지 않았다. `engine.py` 가 `claude-opus-5` 를 상수로 들고 있었을 뿐 근거가 없었다.

그리고 근거를 찾는 과정에서 성능이 결정 요인이 아니라는 것이 드러났다. 2026-08 기준 공개 지능 랭킹은 **상위 6개가 3점 안**에 있다(Claude Opus 5 = 63, Fable 5 = 62, GPT-5.6 Sol = 61, Grok 4.6·Kimi K3·GLM-5.3 = 60). 분야별 1위도 갈린다 — 코딩은 Fable 5, 과학추론은 Gemini 3.1 Pro, 컴퓨터 사용은 GPT-5.4. **어느 것도 "정형 데이터 → 구조화된 매매 판단"과 직결되지 않는다.** 한국어 성능을 가르는 공개 벤치마크는 **찾지 못했다.**

대신 이 프로젝트에만 걸리는 제약이 있다. [ADR 0006](0006-edge-hypothesis.md) 의 F2·F3 가 불일치쌍 85건 ≈ **9.5개월**을 요구하고, [ADR 0007](0007-judgment-engine.md) 이 그 기간 모델 동결을 못박았다. **모델이 중간에 은퇴하면 표본이 층으로 갈리고 시계가 다시 간다.**

## 검토한 선택지

| # | 안 | 판정 |
|---|---|---|
| 1 | 성능 1위 모델을 고른다 | 기각. 상위권이 3점 안에 몰려 있고, 이 과제에서의 우위가 측정된 바 없다 |
| 2 | 가장 싼 모델을 고른다 | 기각. 3개월 페이퍼 총액이 $60~170 규모다 — 비용은 이 설계의 제약이 아니다 |
| 3 | **은퇴 보장 기간이 가장 긴 모델을 고르고, 제공자는 갈아끼울 수 있게 둔다** | **채택** |
| 4 | 한 제공자에 고정하고 어댑터를 만들지 않는다 | 기각. 제공자 리스크(정책·가격·가용성)에 대한 대비가 없고, 어댑터 비용이 낮다 |

## 결정

> **기본 모델은 `claude-opus-5` 로 한다. 제공자 어댑터를 두어 GPT 로 갈아끼울 수 있게 하되, 한 쌍 안에서 섞지 않고 페이퍼 기간에는 동결한다. 그리고 은퇴 보장 하한에서 역산한 페이퍼 착수 마감은 2026-10-09 다.**

### 모델

| 모델 | 단가 (입력/출력, $/1M) | 은퇴 보장 하한 |
|---|---|---|
| **`claude-opus-5`** | 5 / 25 | **2027-07-24** |
| `claude-sonnet-5` | 2 / 10 | 2027-06-30 |
| `claude-fable-5` | 10 / 50 | 2027-06-09 |
| `claude-opus-4-8` | 5 / 25 | 2027-05-28 |
| `claude-haiku-4-5` | 1 / 5 | 2026-10-15 |

`claude-opus-5` 가 **보장 기간 최장 · 지능 랭킹 1위 · 가격 중간**이다. 세 축이 동시에 맞는 유일한 선택지다.

`claude-fable-5` 는 쓰지 않는다 — 2배 비싸고(10/50) 보장 기간은 더 짧으며(2027-06-09), 이 과제에서의 우위가 측정된 바 없다. `claude-haiku-4-5` 는 2026-10-15 은퇴 가능이라 애초에 후보가 아니다.

### 제공자

`AIK_LLM_PROVIDER` / `AIK_LLM_MODEL` 로 갈아끼운다. 다만 **두 가지를 강제한다.**

1. **한 쌍 안에서 섞지 않는다.** `decide_pair()` 가 제공자·모델을 한 번 정해 두 arm 에 같은 것을 쓴다
2. **교체 사실이 남는다.** `decisions.provider` · `model` · `prompt_sha256` · `api_params` 를 결정 행에 봉인한다

### ★ 착수 마감 — 2026-10-09

```
claude-opus-5 은퇴 보장 하한   2027-07-24
F2·F3 표본 소요               − 9.5개월
──────────────────────────────────────
페이퍼 착수 마감               2026-10-09
```

이 날짜를 넘기면 **F2·F3 표본이 다 차기 전에 보장 기간이 끝난다.**

## 근거

### 성능은 변별력이 없고, 캘린더는 있다

상위 6개가 3점 안이면 모델 선택으로 얻는 성능 차이는 이 시스템의 다른 불확실성(브리핑 품질·유니버스 구성·시점 규칙)에 묻힌다. 반면 은퇴는 **표본을 통째로 무효화**한다 — F2·F3 가 `(provider, model, prompt_id)` 층으로 갈리기 때문이다(ADR 0007 동결 정책).

### 앞으로의 하한선을 공개하는 곳은 하나뿐이다

| 제공자 | 사전 공개 |
|---|---|
| **Anthropic** | **모델별 "이 날짜보다 빨리는 은퇴하지 않는다"를 문서에 명시** + 최소 60일 사전 통지 |
| OpenAI | GA 모델 6개월 통지(특수 변형 3개월). 미래 보장 날짜는 공개하지 않음 |
| Google | "가장 이른 가능 날짜"만 공개. Gemini 3.x 안정 모델은 **종료일 자체가 미발표**, 안정 모델 고정 통지기간 없음 |

유효성 전체가 "중간에 안 바뀜"에 걸린 프로젝트에서는 **계획을 세울 수 있는가**가 성능보다 중요하다. 60일 통지는 9.5개월 실험을 구제하지 못하지만, 모델별 하한이 공개돼 있으면 **애초에 다 채울 수 있는 창을 골라 시작할 수 있다.**

### 어댑터를 두되 섞지 않는 이유

두 arm 을 다른 제공자로 돌리면 `Arm 1 − Arm 2` 차이에 제공자 차이가 섞여 **F3 가 브리핑이 아니라 모델 차이를 잰다.** 이는 [ADR 0009](0009-entry-timing.md) 가 봉투를 전 arm 공통으로 둔 것과 같은 논리다 — 재려는 것 외의 모든 것은 양변에 같아야 한다.

### 정확성은 제공자에 의존하지 않는다

OpenAI strict 모드는 `pattern`·`minLength`·`minimum`·`format` 을 강제하지 않는다(구조만 잡고 값은 보지 않는다). 그런데 `engine.decide()` 가 응답을 받은 뒤 로컬 `jsonschema` 로 전체를 다시 검증하므로 **정확성은 제공자와 무관하고, 달라지는 것은 재시도율뿐이다.** ADR 0007 의 *"강제됐다는 말과 강제됐는지 확인하는 것은 다르다"* 가 여기서 값을 한다 — 그 원칙이 제공자 교체를 안전하게 만든다.

### 재현성을 파라미터로 사지 않는다

Claude 4.7 이후 `temperature`·`top_p`·`top_k` 는 400 이다. 이것은 제공자 선택의 근거가 되지 못한다 — [ADR 0003](0003-ai-decides-last.md) 이 이미 비결정성을 감수했고 [ADR 0007](0007-judgment-engine.md) 이 재현의 단위를 **출력의 동일성이 아니라 입력의 증명 가능성**으로 옮겼기 때문이다. `temperature=0` 도 실제 결정성을 주지 않는다.

## 감수하는 비용

- **더 나은 모델이 나와도 페이퍼 기간에는 못 바꾼다.** 바꾸면 표본이 갈리고 85건 시계가 다시 간다. 이 마찰은 의도된 것이다
- **`claude-opus-5` 의 보장 하한이 마감을 만든다.** 착수가 2026-10-09 를 넘으면 실험 도중에 보장이 끝나고, 그때는 층을 갈라 다시 세거나 모델을 옮겨야 한다
- **제공자 어댑터가 유지 지점을 하나 늘린다.** 두 제공자의 응답 모양·파라미터·중단 사유가 각각 바뀔 수 있다
- **한국어 성능을 근거 없이 고른 셈이다.** 공개 벤치마크를 찾지 못했고, 페이퍼 이전에 이것을 측정할 계획도 없다

## 재검토 조건

- **`claude-opus-5` 에 은퇴 통지가 오면** 즉시 이 ADR 을 개정한다. 페이퍼 진행 중이면 잔여 표본과 남은 기간을 비교해 **층을 갈라 계속할지, 옮길지**를 그때 정한다
- **착수가 2026-10-09 를 넘기면** 마감을 다시 계산한다 — 그 시점의 최장 보장 모델이 무엇인지가 답을 바꾼다
- **F2 가 기각되면** 모델 선택 자체가 무의미해진다(ADR 0006 F2 의 행동: AI 판단 엔진 축소). 이 ADR 은 그때 폐기된다
- 한국어 성능을 가르는 근거가 생기면 재검토한다. 다만 **페이퍼 기간 중에는 바꾸지 않는다**

## 확인하지 못한 것

- **한국어 매매 판단에서의 모델 간 성능 차.** 공개 벤치마크는 번역 지표(BLEU 58~64 · COMET 0.80~0.82)뿐이고 이 과제와 거리가 멀다
- 위 은퇴 하한은 **Anthropic 운영 플랫폼 기준**이다. Bedrock·Vertex 등 파트너 플랫폼은 자체 일정을 가지며 다를 수 있다
